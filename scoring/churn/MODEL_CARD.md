---

## Intended Use

harmoni uses `ChurnPredictor` to flag accounts at risk of deal abandonment. The churn probability and risk tier directly drive the NBA orchestrator:

| Risk Tier | Probability | NBA Action |
|---|---|---|
| LOW | 0.00 – 0.20 | Monitor; no action required |
| MEDIUM | 0.20 – 0.50 | Trigger `RE_ENGAGE` nurture sequence |
| HIGH | 0.50 – 0.75 | Trigger `EXEC_ESCALATION` or `DEAL_REVIEW` |
| CRITICAL | 0.75 – 1.00 | Flag for immediate human intervention |

**Out-of-scope use**: Individual contact churn scoring. Predictions must always roll up to the `Account` entity (domain key). Contact-level churn analysis violates the account-first rule in CLAUDE.md.

## Input Features

Identical feature set to `IntentNetworkModel` (same `AccountFeatureVector`). Churn uses anti-correlated feature weights relative to intent — disengagement signals that suppress intent score will elevate churn probability.

| # | Feature | Churn Signal Direction | Notes |
|---|---|---|---|
| 0 | `total_signals_7d` | Negative (more = less churn) | |
| 5 | `high_intent_signals_7d` | Strongest negative | Absence of pricing/demo activity is a major churn indicator |
| 7 | `negative_signals_7d` | Strongest positive | Unsubscribes, bounces drive churn probability up |
| 8 | `negative_signals_30d` | Positive | |
| 13 | `c_suite_vp_signals_7d` | Negative | Executive disengagement is a leading churn signal |
| 14 | `committee_coverage_pct_30d` | Negative | Low coverage (one person still engaging) = deal stalling |
| 15 | `velocity_7d` | Negative | Declining velocity → churn risk |
| 17 | `days_since_last_signal` | Positive | Disengagement: longer gap → higher churn |

Full feature descriptions are in `scoring/intent/MODEL_CARD.md` (features are shared).

**Preprocessing**: StandardScaler included in artifact pipeline. No external preprocessing required at inference.

## Model Architecture

```
Pipeline([
    ("scaler", StandardScaler()),
    ("clf",    LogisticRegression(
                   C=0.5,                  # stronger regularization than intent model
                   class_weight="balanced",
                   max_iter=1000,
                   random_state=42,
               )),
])
```

`C=0.5` (vs `C=1.0` for the intent model) applies stronger L2 regularization. Churn data in production is expected to be noisier than intent data because accounts can recover from signals that look like churn — tighter regularization reduces overfitting to early disengagement signals that reverse.

## Risk Tier Thresholds

Implemented in `scoring.churn.model._classify_risk()`:

```python
if prob >= 0.75:   return ChurnRiskLevel.CRITICAL
if prob >= 0.50:   return ChurnRiskLevel.HIGH
if prob >= 0.20:   return ChurnRiskLevel.MEDIUM
return             ChurnRiskLevel.LOW
```

Threshold selection rationale: The 0.50 / 0.75 split reflects operational cost asymmetry — a false CRITICAL alert consumes senior sales time, while a missed HIGH alert loses a deal. Thresholds should be recalibrated after collecting real ground truth via precision-recall analysis at each operating point.

## Known Limitations

1. **Synthetic training data**: Same as intent model. Requires retraining against labeled CRM closed-lost outcomes for production-grade performance.

2. **No temporal recovery modeling**: An account that churns and then re-engages is treated identically to one that never churned. A future hidden Markov model or sequence model would capture state transitions.

3. **Shared feature set with intent model**: By design, churn is anti-correlated with intent. This means the two models can disagree only marginally for accounts in the "disengaged" bucket — edge cases where signals are mixed are not well-distinguished by either model alone. A joint model or ensemble may reduce this gap.

4. **30-day prediction horizon fixed**: The model does not support variable prediction windows. Deals with longer or shorter typical sales cycles are not served well by a single 30-day window.

5. **Cold start**: Accounts with fewer than 7 days of data will have sparse features (velocity=0, decayed_score_7d=0). Churn probability will be near baseline and not actionable.

## Governance

- **Owner**: harmoni ML team
- **Review cadence**: Quarterly; trigger retrain when recall on HIGH/CRITICAL tier drops below 0.65 on backtested closed-lost deals
- **Bias risk**: Accounts that are culturally email-averse (APAC markets, government) will generate high `days_since_last_signal` and `negative_signals_30d` from opt-outs, potentially inflating churn probability. Region-specific calibration is a future work item
- **Data privacy**: No PII used as model features. Inputs are aggregated behavioral counts at account level only
